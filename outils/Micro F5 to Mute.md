# Micro F5 to Mute
1. Install & Open [Karabiner app](https://karabiner-elements.pqrs.org/)
2. Install & open [Micdrop](https://getmicdrop.com/)
3. Change f5 function key to f5 in Karabiner (i.e. f5 -> f5)
4. Click into Mic Drop icon in menu bar -> Preferences -> Change keyboard shortcut to f5
